About this prototype

Learning the Flask request-to-response cycle.

Café Kouis is a small EGN475 practice project. The home and about URLs are each mapped to a Python function in app.py, and each function returns an HTML template.

Project goal

Keep the structure understandable.

The project separates route logic, templates, and styling. That organization makes it easier to find the code that controls a page, update its content, and add future pages without putting everything in one file.
